# Beanstalk Conductor Image Prompts

This folder holds prompts for generated Beanstalk Conductor art before the images are created and moved into
`../assets/`.

Tone target:

- cartoon-technical, in the spirit of Hop David-style explanatory blog diagrams
- simple, readable shapes that do not hide the technical idea
- features may be intentionally vague when the object is conceptually large, such as a station or shipyard
- clean, technical infrastructure that looks competently designed
- do not make the infrastructure look intentionally dysfunctional, rusty, improvised, or broken
- visually bureaucratic public space infrastructure where appropriate
- physically legible objects over abstract sci-fi decoration
- no Star Trek references or protected franchise styling
- clear silhouettes that still work in a small browser game canvas

Default sizing:

- background or large scene assets: 2048 x 2048 px
- small in-canvas object sprite source files: 512 x 512 px
- portrait/dialog assets: 1024 x 1024 px
- backstory or about-page illustrations may use larger versions of the same subject
- all in-game object assets should state both source pixel size and intended displayed footprint

Each prompt file should state its intended pixel size explicitly before generation.
